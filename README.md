# Purpose

## Steps:
* Create a folder  website-project
* git init for initialize the project for git
* Create index.html in main branch and pushed the code to git hub 
* Create feature/navigation branch and add navigation bar code to index.html
* Merge the code to main branch from feature/navigation branch then stage the code and push it to git hub repository
* Create feature/footer branch and footer code to index.html and push the code to feature/footer branch.
* Create a pull request and merge the footer code from feature/footer branch to main branch
* Pull the code from git hub to local repository to update your code.
* Create a feature/hero-section branch and add short paragraph and merge the code to main branch after staging and commit 
* Create a feature/contact-form and add a code to index.html and create a form then merge the code to main and push it to git repository
 * Create a feature/testimonials and add a code to index.html and push the code to feature/testimonials branch and then created a pull request to merge the code to main branch.
